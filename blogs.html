Design before
manufacture

Define the part's purpose, loads, mounting points, and manufacturing method before modelling it.

Use sketches and CAD to compare options. Check clearances, assembly access, and maintenance needs with the other subteams.

Testing and
iteration

Set a clear test objective. Record the setup, conditions, measurements, and expected result so tests can be compared.

Review unexpected results for measurement errors or loose connections. Change one relevant variable at a time and record the outcome.

Project
documentation

Keep requirements, drawings, design decisions, and test observations with the project files.

Use clear filenames and revision notes. Check that drawings and CAD models refer to the same version before manufacturing.
